# Дед Мороз — Telegram-бот с видео-поздравлениями

Java 21, Spring Boot 3, TelegramBots API, PostgreSQL, Flyway, Docker, ЮKassa, FAL AI

## О проекте

Коммерческий Telegram-бот, который принимает оплату и автоматически генерирует персональные видео-поздравления.  
Проект реализован на Java 21 и Spring Boot 3 с интеграцией внешних сервисов.

Бот ориентирован на реальный сценарий использования: платежи, асинхронные операции, отказоустойчивость и хранение состояния.

## Кратко о проекте

Бот позволяет пользователю:
- оплатить услугу через ЮKassa (СБП);
- получить персональное видео-поздравление;
- отслеживать статус генерации видео.

## Основные возможности

### Telegram-бот
- Long polling
- Минимальный UX
- Пошаговый сценарий взаимодействия с пользователем

### Онлайн-оплата
- Интеграция с ЮKassa
- Поддержка СБП
- Webhook для подтверждения платежей
- Идемпотентная обработка событий

### Генерация видео
- Интеграция с FAL AI
- Асинхронный опрос статуса генерации
- Таймауты и повторные попытки
- Автоматический возврат средств при ошибке

### Хранение данных
- PostgreSQL
- Состояния пользователей
- Баланс и история операций
- Flyway-миграции

### Инфраструктура
- Docker / Docker Compose
- Конфигурация через переменные окружения

## Архитектура

Проект построен по слоистой архитектуре с явным разделением ответственности.

Основные компоненты:
- Telegram Bot — принимает команды и управляет пользовательским сценарием
- Payment Service — создаёт и обрабатывает платежи
- Webhook Controller — принимает события от ЮKassa
- Video Generation Service — управляет процессом генерации видео
- Repository Layer — работа с базой данных
- External Clients — FAL AI, ЮKassa
